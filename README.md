# نظام مجمع ناصر الطبي (Nasser Hospital System) 🏥
> **نظام إدارة استشفائية متكامل، متوافق مع البيئة الطبية والسريرية، مصمم بلغة Laravel 12، بنية تحتية RTL وتصميم عصري باللغة العربية.**

---

## 📌 نبذة عن المشروع
تم تطوير نظام **مجمع ناصر الطبي** ليكون حلاً رقمياً متكاملاً لإدارة العمليات الاستشفائية اليومية، متضمناً:
- **إدارة الملفات الطبية للمرضى**: تسجيل البيانات الشخصية، فصيلة الدم، التاريخ المرضي، الحساسيات الدوائية، وأرقام الطوارئ.
- **جدولة المواعيد والكشوفات**: حجز المواعيد حسب الأولوية (عادي، مستعجل، طوارئ) وربطها بالعيادة التخصصية والطبيب المعالج.
- **السجلات والاستشارات الطبية**: توثيق التشخيص السريري، العلامات الحيوية (ضغط الدم، النبض، الحرارة، الوزن)، والوصفات الدوائية (Rx) مع إمكانية الطباعة.
- **إدارة الأقسام والعيادات التخصصية**: عيادة القلب، جراحة العظام، طب الأطفال، الباطنية، وقسم الطوارئ والإسعاف.
- **إدارة الكادر الطبي والوظيفي**: إدارة حسابات الأطباء، موظفي الاستقبال، والإدارة مع نظام صلاحيات محكم (Role Authorization).

## 🚀 تشغيل النظام محلياً (Local Development)

### 1. تشغيل خادم التطبيق (Laravel Server)
```bash
cd "C:\Users\samsung\.gemini\antigravity\scratch\nasser-hospital-system"
php artisan serve
```
أو باستخدام مسار PHP المباشر:
```powershell
& "C:\xampp\php\php.exe" artisan serve
```
سيعمل النظام على الرابط: **`http://127.0.0.1:8000`**

### 2. تشغيل أصول ومجمّع الواجهات (Vite)
*الأصول مبنية وجاهزة مسبقاً في `public/build`، ولكن للتطوير المباشر:*
```bash
npm run dev
```

### 3. إعادة تهيئة قاعدة البيانات والبذور (عند الحاجة)
```powershell
& "C:\xampp\php\php.exe" artisan migrate:fresh --seed
```

### 4. تشغيل الاختبارات الآلية (Testing Suite)
```powershell
& "C:\xampp\php\php.exe" artisan test
```
